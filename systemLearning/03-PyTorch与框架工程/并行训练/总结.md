DP：切 batch
    每卡有一份完整模型，处理不同样本；
    反向后同步梯度。

EP：切 MoE 专家
    不同卡放不同专家；
    token 根据 router 的结果 all-to-all 发到对应专家卡计算。

PP：切层
    不同卡放不同层；
    micro-batch 在流水线中依次经过各 stage。

TP：切层内张量/权重
    例如切 attention head、MLP hidden 维；
    多卡共同完成“同一层、同一批 token”的矩阵计算，
    中间需要 all-reduce / all-gather 等通信。

CP：切 sequence，但 attention 也保持切分
    每卡持有一段 token 的本地 Q、K、V；
    每卡负责本段 token 的 Q 所对应的 attention 输出；
    为了让本地 Q 看到全上下文，要交换/轮转其他卡的 K/V，
    或通过 all-to-all 重排为 head 分片。
    
SP：也切 sequence，但通常只切非 attention 部分
    每卡只保存一段 token 的 LayerNorm、Dropout、Residual 等 activation；
    到 attention 前会把完整 sequence Gather 回来；
    所以主要省 activation 显存，不切掉 attention 的 S² 计算。
